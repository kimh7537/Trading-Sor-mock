# 시장 규칙 명세

이 문서는 구현의 근거가 되는 시장 규칙을 정리한다.
공개 자료 기준이며, 구현 편의를 위해 단순화한 지점은 명시한다.

**기준 시점**: 2026-09. 규칙은 변경될 수 있으므로 구현 시 이 문서를 단일 출처로 삼는다.

---

## 1. 복수시장 구조

2025년 3월 4일 넥스트레이드(NXT) 출범으로 국내 주식은 두 시장에서 거래된다.

| 구분 | KRX (한국거래소) | NXT (넥스트레이드) |
|---|---|---|
| 성격 | 정규 거래소 | 대체거래소(ATS), 다자간매매체결회사 |
| 기능 | 상장·시장감시·매매체결 | 매매체결만 |
| 거래 종목 | 전 종목 | KRX 상장 종목 중 일부 |
| 청산·결제 | KRX가 양 시장 일괄 수행 | — |

**구현상 함의**
- 종목별로 거래 가능 시장이 다르다. 원장 검증에서 확인해야 한다
- 청산·결제는 이 프로젝트 범위 밖이다

---

## 2. 거래 시간

### 2.1 KRX

| 세션 | 시간 |
|---|---|
| 정규장 | 09:00 ~ 15:30 |

단일가 매매(시가·종가)는 **Phase 1에서 구현하지 않는다.** 연속 체결만 다룬다.
필요 시 별도 태스크로 추가한다.

### 2.2 NXT

| 세션 | 시간 | 비고 |
|---|---|---|
| 프리마켓 | 08:00 ~ 08:50 | 지정가만 |
| 오전 휴장 | 08:50 ~ 09:00:30 | 신규·정정 불가, 취소만 가능 |
| 메인마켓 | 09:00:30 ~ 15:20 | 전 주문 유형 |
| 오후 휴장 | 15:20 ~ 15:30 | 신규·정정 불가, 취소만 가능 |
| 애프터마켓 | 15:30 ~ 20:00 | 지정가만 |

**주의**
- 메인마켓 시작이 09:00이 아니라 **09:00:30**이다. 초 단위까지 정확히 처리한다
- 프리·메인마켓에서 접수한 주문은 애프터마켓까지 유효하다
- NXT 전체 운영 시간은 08:00 ~ 20:00로 KRX보다 길다

**구현상 함의**
- 08:00~09:00 구간과 15:30~20:00 구간에는 NXT만 열려 있다. SOR은 이때 라우팅 선택지가 하나뿐이다
- 이 비대칭이 SOR 테스트의 좋은 케이스가 된다

## 3. 가격 규칙

### 3.1 가격 제한폭

양 시장 모두 전일 종가 기준 **±30%**.

### 3.2 호가 단위

가격대별 최소 가격 변동폭. 아래는 국내 주식시장 기준이다.

| 가격 구간 | 호가 단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 2,000 ~ 5,000원 미만 | 5원 |
| 5,000 ~ 20,000원 미만 | 10원 |
| 20,000 ~ 50,000원 미만 | 50원 |
| 50,000 ~ 200,000원 미만 | 100원 |
| 200,000 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

**구현 시 주의**
- 경계값 처리를 명확히 한다. 2,000원은 5원 단위 구간에 속한다 (이상/미만)
- 코스피와 코스닥의 호가 단위가 다른 구간이 있으나, 이 프로젝트는 **위 표 하나로 통일**한다. 단순화 지점임을 명시한다

## 4. 매칭 규칙

### 4.1 공통 원칙

1. **가격 우선**: 매수는 높은 가격, 매도는 낮은 가격이 우선
2. **시간 우선**: 같은 가격이면 먼저 접수된 주문이 우선

체결 가격은 **먼저 호가창에 있던 주문의 가격**으로 한다.

### 4.2 주문 유형

| 유형 | 동작 | KRX | NXT |
|---|---|---|---|
| 지정가 (LIMIT) | 지정 가격 이하(매수)/이상(매도) 체결, 잔량 호가 등록 | ○ | ○ |
| 시장가 (MARKET) | 반대 호가 소진하며 체결, 잔량 취소 | ○ | 메인마켓만 |
| IOC | 즉시 체결분만, 잔량 취소 | ○ | 메인마켓만 |
| FOK | 전량 즉시 체결 불가 시 전체 취소 | ○ | 메인마켓만 |
| 중간가 (MIDPOINT) | 가격 자동 결정 (아래 참조) | ✕ | 메인마켓만 |

### 4.3 중간가 주문 (NXT 전용)

수량만 지정하고 가격은 자동으로 결정된다.

```
중간가 = (최우선매수호가 + 최우선매도호가) ÷ 2
```

**제약**
- 메인마켓 시간에만 주문 가능
- 다른 주문 유형으로 정정 불가

**구현 시 결정해야 할 것** (`docs/decisions/`에 기록)

1. 중간값이 호가 단위로 떨어지지 않을 때 — 반올림/내림/호가 단위 무시 중 선택
2. 기준가 재계산 시점 — 접수 시점 고정 vs 호가 변동 시마다 갱신
3. 한쪽 호가가 비어 있을 때 — 거부 vs 대기

이 세 가지는 공개 자료만으로는 확정하기 어렵다. **합리적으로 정하고 근거를 문서화한다.**
"실제와 다를 수 있음"을 README에 명시한다.

### 4.4 정정 시 우선순위

| 정정 내용 | 시간 우선순위 |
|---|---|
| 가격 변경 | 상실 (뒤로 이동) |
| 수량 증가 | 상실 |
| 수량 감소 | 유지 |

## 5. SOR (Smart Order Routing)

### 5.1 법적 근거

자본시장법 제68조 최선집행의무. 증권사는 최선집행기준을 수립·공표하고 그에 따라 주문을 집행해야 한다.
투자자가 시장을 지정하지 않으면 SOR이 유리한 시장으로 배분한다.

**중요**: 최선집행기준은 "가장 유리한 결과"를 보장하는 것이 아니라 "가장 유리한 판단 기준"이다.
사후에 결과가 불리했더라도 기준에 따라 판단했다면 의무를 다한 것이다.
따라서 **판단 근거의 기록이 결과 자체보다 중요하다.**

### 5.2 평가 요소

| 요소 | 내용 |
|---|---|
| 가격 | 시장별 최우선 반대호가 |
| 체결 가능성 | 해당 가격대 잔량, 최근 체결 빈도 |
| 거래 비용 | 시장별 수수료율 |
| 시장 상태 | 현재 시각에 해당 시장이 열려 있는가 |

가중치는 설정 파일로 분리한다. 증권사마다 기준이 다르다는 점을 반영한 설계다.

### 5.3 집행 전략

| 전략 | 동작 | 용도 |
|---|---|---|
| KRX_ONLY | 전량 KRX | 기준선. SOR 도입 이전 상태 |
| BEST_PRICE | 최우선 가격이 유리한 한 시장에 전량 | 단순 라우팅 |
| SPLIT | 양 시장 잔량에 비례 분할 | 대량 주문 |
| SWEEP | 유리한 시장부터 잔량만큼 채우고 나머지를 다른 시장으로 | 즉시 체결 우선 |

**측정**: 동일 주문·동일 시드로 네 전략을 각각 실행해 평균 체결 단가, 슬리피지, 체결률을 비교한다.
KRX_ONLY 대비 개선폭을 bp 단위로 산출한다.

### 5.4 논리 주문과 물리 주문

사용자가 낸 주문 1건이 시장별로 쪼개져 나갈 수 있다.

```
논리 주문 (사용자 관점, 화면에 한 줄)
  ├─ 물리 주문 A → KRX
  └─ 물리 주문 B → NXT
```

**상태 전이 규칙**

- 논리 주문 상태는 물리 주문들의 상태로부터 유도한다
- 전량 체결: 모든 물리 주문이 FILLED
- 부분 체결: 하나 이상 체결, 전량은 아님
- 취소: 모든 물리 주문이 CANCELED
- **부분 취소**: 한쪽만 취소 성공한 상태. 별도 상태로 정의하고 처리 방침을 정한다

**취소의 어려움**

분할된 주문을 취소할 때 한쪽은 성공, 다른 쪽은 이미 체결되어 실패할 수 있다.
원자적 취소는 불가능하다. 보상 처리 방침을 정의하고 문서화한다.

## 6. 단순화 지점

실제와 다르게 구현한 부분. README에도 동일 내용을 기재한다.

| 항목 | 실제 | 이 프로젝트 |
|---|---|---|
| 단일가 매매 | 시가·종가 단일가 존재 | 미구현. 연속 체결만 |
| 호가 단위 | 시장·종목별 차이 존재 | 단일 테이블로 통일 |
| 청산·결제 | KRX가 수행 | 범위 밖 |
| 증거금 | 종목·계좌별 복잡한 산정 | 단순 현금 잔고 기준 |
| 거래 가능 종목 | NXT 종목 단계적 확대 | 설정 파일로 고정 |
| 중간가 세부 규칙 | 공개 자료 불충분 | 자체 판단, 근거 문서화 |
| 시장 감시 | KRX 수행 (CB, 사이드카 등) | 미구현 |
| 수수료 | 증권사·시장별 상이 | 설정 파일로 단순 정률 |
